# AI Demand & Growth / AI 需求与增长

## When to Use / 使用场景

- **EN**: A team needs systematic demand generation rather than scattered posts. Leads arrive but don't convert. You want growth loops instead of a linear funnel, plus a weekly growth cadence to keep the system honest.
- **中文**：团队需要系统化的需求生成，而非零散发帖。线索来了却不转化。希望用增长飞轮替代线性漏斗，并用周度节奏让系统不失真。

## Core Principles / 核心原则

1. **Demand gen is a system, not a campaign / 需求生成是系统不是活动** — design loops that compound, not one-off pushes. / 设计会复利的飞轮，而非一次性推动。
2. **Blend paid + organic + lifecycle / 付费+自然+生命周期组合** — no single channel carries growth alone. / 没有单一渠道能独立支撑增长。
3. **Growth loops over linear funnel / 增长飞轮优于线性漏斗** — each user should pull the next (referral, UGC, data network effect). / 每个用户都应拉来下一个。
4. **Measure per-channel ROI / 按渠道算 ROI** — fund what compounds, cut what doesn't. / 给复利者加注，砍掉无效者。
5. **Weekly cadence / 周度节奏**: review signals, grade, and decide — every week, not once a quarter. / 每周复盘信号、分级、决策。

## Procedure / 操作流程

1. **Map the funnel & channels / 梳理漏斗与渠道**: list where demand enters and where it leaks. / 列出需求从哪进、在哪漏。
2. **Build the mix / 搭组合**: allocate to paid, SEO/content, events/community, referral. / 在付费、SEO/内容、活动/社区、转介绍间分配。
3. **Lifecycle nudges / 生命周期触达**: onboarding, activation prompt, win-back — automated but human-toned. / 引导、激活提示、召回——自动化但有温度。
4. **Set up tracking / 建追踪**: UTM + product events so every channel has a measurable ROI. / UTM+产品事件，让每渠道 ROI 可衡量。
5. **Weekly growth review / 周度增长复盘**: grade signals, decide next actions, name owners. / 分级信号、定下一步、指负责人。

## Gotchas / 常见陷阱

- **Treating growth as a one-off campaign / 把增长当一次性活动** burns budget and teaches nothing. Build loops. / 烧钱且无积累，要建飞轮。
- **No attribution means no learning / 没有归因就没有学习.** Without UTM/events, you can't tell which channel compounds. / 无 UTM/事件就分不清哪个渠道在复利。
- **Ignoring retention kills acquisition ROI / 忽视留存会毁掉获客 ROI.** Acquiring users who churn is a leaky bucket. / 拉来就走是漏桶。
- **A review with no actions is a dashboard / 没有动作的复盘只是仪表盘.** Every signal needs a "so what" and an owner. / 每个信号都要有「所以呢」和负责人。
- **Vanity lead volume / 虚荣线索量**: leads that never activate inflate the top without filling the bottom. / 不激活的线索只胀头部不填底部。
- **One channel only is fragile / 只靠一个渠道很脆弱.** Algorithm or policy change can zero your pipeline overnight. / 算法或政策一变，管道可能一夜归零。

## Checklist / 自检清单

- [ ] Is demand gen designed as loops, not one-off pushes? / 需求生成是否设计成飞轮而非一次性推动？
- [ ] Does every channel have a measurable ROI? / 每个渠道是否都有可衡量 ROI？
- [ ] Is retention tracked alongside acquisition? / 留存是否与获客一同追踪？
- [ ] Does the weekly review end with owners and dates? / 周度复盘是否落到负责人与日期？
- [ ] Are all numbers in the review defensible? / 复盘里的数字是否都可自证？

## Shared Context / 共享原则

- Outcomes over output: we measure whether users adopt and convert, not whether they liked the post. / 重结果而非产出。
- Evidence-based: cite real signals and proof; never invent metrics or claims. / 基于证据，绝不编造。
- Audience respect: no hype, no fake "best", no jargon without translation. / 尊重用户，不炒作、不编造、黑话必译。
- AI is a lever, not autopilot: AI drafts and analyzes; a human owns the message and the judgment. / AI 是杠杆不是自动驾驶。
- Client confidentiality: protect client data and unreleased plans. / 客户保密。
