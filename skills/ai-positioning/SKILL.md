# AI Positioning / AI 产品定位

## When to Use / 使用场景

- **EN**: A product is launching, rebranding, or struggling to explain what it does. Marketing content drifts because there is no shared positioning anchor. Sales and marketing tell different stories about the same product.
- **中文**：产品正在发布、重塑品牌，或讲不清自己是什么。市场内容各自为政，因为缺少统一的定位锚点。销售与市场对外讲的故事不一致。

## Core Principles / 核心原则

1. **Positioning before content / 定位先于内容** — every blog post, ad, and launch traces back to one positioning statement. / 每篇推文、广告、发布都回归同一条定位陈述。
2. **One persona at a time / 一次聚焦一类人群** — "everyone" is not a persona; name the specific user and their job. / 「所有人」不是人群，要指名具体用户及其任务。
3. **Differentiate on a job, not a feature / 用结果而非功能来差异化** — lead with the outcome the user can't get elsewhere. / 先讲用户在他处得不到的结果。
4. **Evidence over adjectives / 证据胜过形容词** — claims need proof (benchmark, case study, demo), not "best-in-class". / 主张要有证据（基准测试、案例、演示），而非「行业领先」。
5. **Small test before broadcast / 先小范围验证再放大** — validate the message on a small audience before scaling spend. / 在扩大投放前，先用小受众验证信息。

## Procedure / 操作流程

1. **Intake / 收集信息**: capture the product, current pitch, and the 3 alternatives the user compares it against. / 收集产品、当前话术，以及用户做对比时最常被提到的 3 个替代方案。
2. **Persona / 用户画像**: name one primary persona — role, context, trigger event, current workaround. / 定义一位核心用户：角色、场景、触发事件、当前替代方案。
3. **Positioning statement / 定位陈述**: fill the template below. / 套用下方模板。
4. **Messaging hierarchy / 信息层级**: one anchor message + 3 supporting pillars, each with proof. / 一条锚定信息 + 3 个支撑支柱，每根支柱配证据。
5. **Pressure test / 压力测试**: put the statement in front of 3–5 real users (or a proxy); revise on confusion. / 把陈述交给 3–5 位真实用户看，含糊处即改。

## Templates / 模板

### Positioning statement / 定位陈述

> For **[persona]** who **[context / trigger]**, **[product]** is a **[category]** that **[outcome]**. Unlike **[alternative / status quo]**, we **[differentiator with proof]**.
> 面向 **[人群]**（在 **[场景/触发点]** 时），**[产品]** 是一款 **[品类]**，能带来 **[结果]**。不同于 **[替代方案/现状]**，我们 **[有证据支撑的差异化]**。

### Messaging hierarchy / 信息层级

- **Anchor / 锚定**: one sentence the whole market should remember. / 全市场都应记住的一句话。
- **Pillar 1 / 支柱 1** — [claim] · proof: [benchmark / case / demo]
- **Pillar 2 / 支柱 2** — [claim] · proof: [benchmark / case / demo]
- **Pillar 3 / 支柱 3** — [claim] · proof: [benchmark / case / demo]

### Persona card / 用户画像卡

- **Who / 是谁**: [role, seniority, context]
- **Trigger / 触发点**: the moment they go looking for a solution / 他们开始找解决方案的那一刻
- **Today's workaround / 当前做法**: what they do without you / 没有你时他们怎么做
- **Win condition / 赢的条件**: the outcome that makes them stay / 让他们留下来的结果

## Gotchas / 常见陷阱

- **A positioning statement nobody inside can repeat is worthless / 连内部都复述不出的定位毫无价值.** If the founder can't say it in one breath, simplify until it fits. / 创始人若不能一口气说完，就继续精简。
- **Don't position against a competitor the user hasn't heard of / 别拿用户没听过的对手做对照.** Position against the status quo they actually use. / 对照他们真正在用的现状。
- **Persona drift kills the whole funnel / 人群漂移会毁掉整个漏斗.** Pick one persona; let other segments come later. / 先选准一类人，其余段位以后再说。
- **Unverifiable proof gets challenged publicly / 无法验证的证据会被公开质疑.** Use real, citable numbers or frame as illustrative. / 用可引用的真实数据，或明确标注为示意。
- **Don't let internal jargon leak into external messaging / 别让内部黑话漏到对外信息里.** Translate to the job the user is hiring you for. / 翻译成用户雇你来解决的那件事。

## Checklist / 自检清单

- [ ] Is there one positioning statement the founder can say in one breath? / 创始人能否一口气说完定位？
- [ ] Is the primary persona named, not "everyone"? / 核心人群是否具体而非「所有人」？
- [ ] Does every claim have a proof pointer? / 每个主张是否都有证据指向？
- [ ] Has the statement survived a test with real users? / 是否经真实用户测试通过？

## Shared Context / 共享原则

- Outcomes over output: we measure whether users adopt and convert, not whether they liked the post. / 重结果而非产出：看用户是否转化，而非是否喜欢内容。
- Evidence-based: cite real signals and proof; never invent metrics or claims. / 基于证据：引用真实信号与证明，绝不编造数据。
- Audience respect: no hype, no fake "best", no jargon without translation. / 尊重用户：不炒作、不假称「最佳」、黑话必翻译。
- AI is a lever, not autopilot: AI drafts and analyzes; a human owns the message and the judgment. / AI 是杠杆不是自动驾驶：AI 起草与分析，人掌握信息与判断。
- Client confidentiality: protect client data and unreleased plans. / 客户保密：保护客户数据与未公开计划。
