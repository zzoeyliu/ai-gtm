# AI Competitive Intelligence / AI 竞争情报

## When to Use / 使用场景

- **EN**: A team wants to know what the market says about them and competitors. Content feels disconnected from what the audience actually asks. Sales hears the same objection repeatedly but nothing flows back to marketing.
- **中文**：团队想知道市场如何评价自己与竞品。内容与市场真正关心的问题脱节。销售反复听到同一异议，却没回流到市场。

## Core Principles / 核心原则

1. **Listen where the audience is / 去用户在的地方听** — search, forums, social, review sites, communities, not just the brand's own channels. / 搜索、论坛、社媒、点评、社区，而非只看自有渠道。
2. **Classify signal before reacting / 先分类再反应** — a complaint, a feature ask, a competitor switch, and a praise are four different actions. / 投诉、功能请求、竞品迁移、好评是四种不同动作。
3. **Every signal is a content brief / 每个信号都是选题** — the best posts answer a real, recurring question. / 好内容回答真实且反复出现的问题。
4. **Join, don't broadcast / 加入而非广播** — in community spaces, answer the question; mention the product only when it's the answer. / 在社区里先答问题，产品只是答案时才提。
5. **Protect trust / 守护信任**: never fake a user, never astroturf, never quote people out of context. / 绝不伪造用户、绝不水军、绝不断章取义。

## Procedure / 操作流程

1. **Source map / 来源地图**: list relevant channels (owned + 2–3 community spaces + search terms). / 列出相关渠道（自有+2–3 社区+搜索词）。
2. **Collect / 采集**: pull recurring threads weekly; tag each by signal type. / 每周抓取高频讨论，按信号类型打标。
3. **Triage / 分级**: grade by frequency and intent (see taxonomy). / 按频率与意图分级。
4. **Route / 路由**: feedback → product; objection → content; competitor → battlecard; praise → proof. / 反馈→产品；异议→内容；竞品→打击卡；好评→证据。
5. **Act / 行动**: turn the top signal into a content piece or a community reply within the week. / 一周内把头号信号变成内容或社区回复。

## Signal Taxonomy / 信号分类

| Signal / 信号 | Example / 示例 | Action / 动作 |
|---|---|---|
| Pain / 痛点 | "X is a pain to set up" | Content: setup guide / 内容：上手指南 |
| Feature ask / 功能请求 | "Wish it had Y" | Product feedback + waitlist / 产品反馈+候补 |
| Competitor switch / 竞品迁移 | "moving from A to B" | Battlecard + comparison / 打击卡+对比 |
| Objection / 异议 | "too complex for my team" | Content: simpler path / 内容：更简单路径 |
| Praise / proof / 好评证据 | "shipped in a day" | Testimonial, case study / 证言、案例 |
| Confusion / 困惑 | "not sure what it does" | Positioning fix / 定位修正 |

## Templates / 模板

### Weekly signal digest / 周度信号摘要

```
# Listening Digest (YYYY-Www) / 监听摘要
- Top signal / 头号信号: [verbatim quote] → action: [content / feedback / battlecard]
- Recurring ask / 反复诉求: [topic] → backlog it / write it
- Competitor chatter / 竞品声量: [who said what] → note for next campaign
- Confusion to fix / 待修困惑: [where] → positioning or docs fix
```

### Competitive battlecard / 竞品打击卡

- **Competitor / 竞品**: [name]
- **They say / 对方主张**: [their positioning]
- **We win when / 我方胜出场景**: [use case where we are stronger]
- **Objection handling / 异议处理**: [common objection → our response with proof]
- **Proof / 证据**: [benchmark / case / demo]

### Community reply / 社区回复 (seed, not shout)

> Saw this come up a few times — here's the shortest path we found: [link]. Happy to go deeper if useful.
> 看到好几次有人问——这是我们找到的最短路径：[链接]。有用就好，想深挖随时找我。

## Gotchas / 常见陷阱

- **Listening without acting is just a dashboard / 只听不做只是仪表盘.** If the top signal produces no content or note, the loop is broken. / 头号信号若没产出内容或记录，闭环就断了。
- **Astroturfing destroys a brand permanently / 水军会永久毁掉品牌.** Never post fake questions or praise. / 绝不发假问题或假好评。
- **Answering with a link and no help reads as spam / 只甩链接不帮忙像 spam.** Give the answer first, link second. / 先给答案，链接其次。
- **Don't over-react to one loud voice / 别对单一大声者过度反应.** Grade by frequency across sources. / 按跨来源频率分级。
- **Quoting users without context backfires / 断章取义引用户会反噬.** Get permission or anonymize. / 要授权或匿名。
- **Search questions are the highest-intent signal / 搜索提问是最高意图信号.** "how do I X with Y" with volume is a content brief with built-in demand. / 有量的「如何用 Y 做 X」是自带需求的选题。

## Checklist / 自检清单

- [ ] Do we have a source map covering owned + community + search? / 是否覆盖自有+社区+搜索的来源地图？
- [ ] Is every signal tagged by type and routed to an action? / 每个信号是否分类并路由到动作？
- [ ] Did the top signal produce a content piece or note this week? / 头号信号本周是否产出内容或记录？
- [ ] Are we joining conversations, not just broadcasting? / 是否加入对话而非只广播？

## Shared Context / 共享原则

- Outcomes over output: we measure whether users adopt and convert, not whether they liked the post. / 重结果而非产出。
- Evidence-based: cite real signals and proof; never invent metrics or claims. / 基于证据，绝不编造。
- Audience respect: no hype, no fake "best", no jargon without translation. / 尊重用户，不炒作、不编造、黑话必译。
- AI is a lever, not autopilot: AI drafts and analyzes; a human owns the message and the judgment. / AI 是杠杆不是自动驾驶。
- Client confidentiality: protect client data and unreleased plans. / 客户保密。
