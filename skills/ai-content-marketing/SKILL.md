# AI Content Marketing / AI 内容营销

## When to Use / 使用场景

- **EN**: A team needs a steady stream of content but can't staff a full editorial team. Content exists but doesn't convert. You want AI to multiply a small team's output without sounding robotic.
- **中文**：团队需要稳定内容产出，但养不起完整编辑团队。内容有了却没转化。希望用 AI 放大小团队产能，又不显机械。

## Core Principles / 核心原则

1. **Mine topics from signal, not a calendar / 从信号而非日历挖选题** — the best content starts in forums, search, and "how do I…" questions. / 好内容始于社区、搜索与「怎么做……」的提问。
2. **One piece, one job / 一篇内容一个任务** — every article or post exists to move a user one step down the funnel. / 每篇内容都为推动用户前进一步而存在。
3. **AI drafts, human steers / AI 起草，人掌舵** — AI produces most of the words; a human owns the claim, the example, and the voice. / AI 写大部分文字，人负责论点、案例与语气。
4. **Write once, adapt many / 一次写好，多次改编** — produce a strong long-form piece, then slice it into social, docs, and replies. / 先出一篇扎实长文，再切片成社媒、文档与评论。
5. **Small test before the long version / 长文之前先试角度** — validate the angle with a short post before investing in a long guide. / 写长文前先用短帖验证角度。

## Procedure / 操作流程

1. **Mine / 挖掘**: pull recurring questions from search console, forums, social, and reviews. / 从搜索词、社区、社媒、评价中收集高频问题。
2. **Decide the job / 定任务**: pick the funnel stage each topic serves (awareness / signup / activation / retention). / 为选题选定所属漏斗阶段。
3. **Draft with AI / AI 起草**: feed topic + positioning + proof into the AI; require a concrete example and a cited source. / 把选题+定位+证据喂给 AI，要求具体案例与可引用来源。
4. **Adapt / 改编**: turn the long-form into a blog, a docs page, an X thread, a LinkedIn post, a 小红书 note, and a 视频号 script. / 把长文改成博客、文档、X 帖、LinkedIn、小红书、视频号脚本。
5. **Publish & measure / 发布与衡量**: ship, then track reads → clicks → signups per channel; kill what doesn't convert. / 发布后按渠道追踪阅读→点击→注册，转化差者砍掉。

## Templates / 模板

### Topic card / 选题卡

- **Signal source / 信号来源**: [search term / forum / review]
- **Question users ask / 用户提问**: "[verbatim]" / 「原话」
- **Funnel job / 漏斗任务**: [awareness / signup / activation / retention]
- **Proof we can use / 可用证据**: [benchmark / case / demo]

### AI draft brief / AI 起草简报 (give this to the model)

> Write a blog post about [topic]. Audience: [persona]. Voice: [brand-voice link]. Must include a concrete, verifiable example with expected outcome. Cite [source]. End with one clear next step. No hype.
> 写一篇关于 [选题] 的文章。受众：[人群]。语气：[品牌语调链接]。必须含可验证的具体案例与预期结果。引用 [来源]。结尾给一个明确下一步。不炒作。

### Multi-channel slice / 多渠道切片

- **Blog / 博客**: full walkthrough + example. / 完整讲解+案例。
- **X thread / X 帖**: the 3 non-obvious points, one insight per tweet. / 3 个反常识点，一帖一洞察。
- **LinkedIn / LinkedIn**: the "why this matters" framing for decision-makers. / 面向决策者的「为何重要」。
- **小红书 / 小红书**: the personal, first-hand experience angle. / 第一手亲身体验视角。
- **视频号 / 视频号**: the 60-second spoken version with a demo. / 60 秒口播+演示。

## Gotchas / 常见陷阱

- **AI-generated examples that don't hold up destroy trust / 站不住脚的 AI 案例会瞬间摧毁信任.** Verify every claim before publishing. / 发布前核实每一处主张。
- **"Best-in-class" and "revolutionary" repel audiences / 「行业领先」「颠覆性」令人反感.** Describe what changed and let readers judge. / 讲清发生了什么变化，交给读者判断。
- **Don't ship the long guide before testing the angle / 别在验证角度前就写长文.** A long tutorial built on a wrong assumption is the expensive version of a bad bet. / 基于错误假设的長文是昂贵版的错误赌注。
- **One post, one action / 一篇一动作.** If you can't name the single next step, the draft isn't finished. / 说不清下一步，草稿就没写完。
- **Slicing without re-voicing sounds like spam / 只复制不重写的切片像 spam.** Each channel needs its own opening. / 每个渠道都要有自己的开场。
- **Measure conversion, not likes / 衡量转化而非点赞.** A post with reach but zero signups is a vanity win. / 有曝光零注册只是虚荣指标。

## Checklist / 自检清单

- [ ] Did the topic come from a real user signal? / 选题是否来自真实用户信号？
- [ ] Does the draft have a verifiable example? / 草稿是否有可验证案例？
- [ ] Is there one clear next step for the reader? / 读者是否有一个明确下一步？
- [ ] Is each channel slice re-voiced, not copy-pasted? / 各渠道是否重写而非复制？
- [ ] Are we tracking signups, not just reads? / 是否追踪注册而非只看阅读？

## Shared Context / 共享原则

- Outcomes over output: we measure whether users adopt and convert, not whether they liked the post. / 重结果而非产出。
- Evidence-based: cite real signals and proof; never invent metrics or claims. / 基于证据，绝不编造。
- Audience respect: no hype, no fake "best", no jargon without translation. / 尊重用户，不炒作、不编造、黑话必译。
- AI is a lever, not autopilot: AI drafts and analyzes; a human owns the message and the judgment. / AI 是杠杆不是自动驾驶。
- Client confidentiality: protect client data and unreleased plans. / 客户保密。
