# Brand Voice and Tone / 品牌语调

Referenced by all skills and all client-facing content, keeping the whole library consistent.
被所有 skill 与所有对外内容引用，保证全库一致。

## Voice (constant) / 语气（恒定）

- Professional, never condescending. / 专业，但绝不居高临下。
- Concrete, verifiable, fact-based. / 具体、可验证、基于事实。
- Starting point: "help the user succeed". / 出发点：「帮用户成功」。

## Tone (adjusts by scenario) / 语调（随场景调整）

| Scenario / 场景 | Tone / 语调 |
|---|---|
| Docs / tutorials / 文档教程 | Clear, stepwise, neutral / 清晰、分步、中性 |
| Social (X / Reddit / HN) / 社媒 | Relaxed, opinionated, link included, no fluff / 松弛、有观点、带链接、不废话 |
| 小红书 / 小红书 | First-hand, personal, honest / 第一手、个人化、真诚 |
| 视频号 / 视频号 | Spoken, warm, demo-led / 口语、亲切、以演示为主 |
| Announcements / 公告 | Concise, lead with value and the change / 简洁，先讲价值与变化 |
| Client report / 客户报告 | Plain, decision-ready, trend over level / 平实、可决策、看趋势而非单点 |

## Never / 永远不做

- Exaggerated claims ("best", "revolutionary", "game-changing"). / 夸大主张（「最佳」「颠覆性」「改变游戏规则」）。
- Unverified data, benchmarks without method, or promises we can't keep. / 未验证的数据、无方法的基准、无法兑现的承诺。
- Speaking in the client's official voice (unless explicitly authorized). / 冒充客户官方口吻（除非明确授权）。
- Astroturfing, fake users, or quoting people out of context. / 水军、假用户、断章取义引述。
