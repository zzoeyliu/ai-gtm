# Glossary / 术语表

Common marketing, GTM, and AI-product terms, kept consistent across the library. / 全库通用营销、GTM 与 AI 产品术语，保持一致。

| Term / 术语 | Meaning / 含义 |
|---|---|
| **GTM (Go-to-Market) / 市场进入** | How a product reaches and wins its target users — strategy, channels, and execution. / 产品触达并赢得目标用户的方式——战略、渠道与执行。 |
| **AI product / AI 产品** | A product whose core value depends on AI (model, inference, agent, or AI-assisted workflow). / 核心价值依赖 AI（模型、推理、agent 或 AI 辅助流程）的产品。 |
| **Positioning / 定位** | How a product is framed relative to alternatives — who it's for and the job it wins. / 产品相对替代方案的 framing——为谁解决什么问题、凭什么赢。 |
| **Persona / 用户画像** | A named representation of the target user: role, context, trigger, workaround. / 目标用户的具体刻画：角色、场景、触发点、当前做法。 |
| **Messaging hierarchy / 信息层级** | One anchor message plus supporting pillars, each with proof. / 一条锚定信息加若干支撑支柱，每根配证据。 |
| **Content engine / 内容引擎** | A repeatable pipeline that turns signals into published, multi-channel content. / 把信号变成已发布多渠道内容的可复用管线。 |
| **Channel mix / 渠道组合** | The set of channels (X, LinkedIn, 小红书, 视频号, HN, Product Hunt, communities) and the job each owns. / 各渠道（X、LinkedIn、小红书、视频号、HN、Product Hunt、社区）及其分工。 |
| **Launch cadence / 发布节奏** | A timed checklist (e.g. T-14 → T+7) for shipping a version or feature. / 发布版本或功能的定时清单（如 T-14 → T+7）。 |
| **A/B test / A/B 测试** | Comparing variants of a message or creative to see which converts better. / 对比信息或创意的变体，看哪个转化更好。 |
| **Competitive intel / 竞争情报** | Monitoring market, social, and competitors to extract signals and battlecards. / 监测市场、社媒与竞品，提炼信号与打击卡。 |
| **Signal / 信号** | A recurring observation (pain, ask, objection, praise) that implies an action. / 反复出现的观察（痛点、请求、异议、好评），意味着一个动作。 |
| **Battlecard / 打击卡** | A concise comparison + objection-handling card for competing against a specific rival. / 针对特定对手的简明对比+异议处理卡。 |
| **Demand generation / 需求生成** | The system that creates qualified demand across paid, organic, lifecycle, and referral. / 跨付费、自然、生命周期与转介绍创造合格需求的系统。 |
| **Growth loop / 增长飞轮** | A cycle where each user pulls the next (referral, UGC, data network effect). / 每个用户拉来下一个的循环（转介绍、UGC、数据网络效应）。 |
| **GTM funnel / 营销漏斗** | awareness → signup → activation → retention → advocacy. / 认知→注册→激活→留存→推荐。 |
| **North-star metric / 北极星指标** | The single metric that best captures the value a team delivers. / 最能代表团队所交付价值的单一指标。 |
| **Leading / lagging indicator / 先行/滞后指标** | Leading predicts outcomes (trial starts); lagging confirms them (retained users). / 先行预测结果（试用开始）；滞后确认结果（留存用户）。 |
| **Activation / 激活** | The moment a user first gets value (first successful run / call / output). / 用户首次获得价值的时刻（首次成功运行/调用/产出）。 |
| **Advocacy / 推荐** | When users pull others in (referral, case study, community answer). / 用户拉来他人（转介绍、案例、社区答疑）。 |
| **Agent Skills** | An open skill spec: each skill is a `SKILL.md` with frontmatter, loadable and executable by AI agents. See https://agentskills.io. / 开放技能规范：每个 skill 是带前置元数据的 `SKILL.md`，可被 AI agent 加载执行。见 https://agentskills.io。 |
| **SKILL.md** | The Agent Skills spec file, containing `name` / `description` metadata and the instruction body. / Agent Skills 规范文件，含 `name`/`description` 元数据与指令正文。 |
| **Progressive disclosure / 渐进式披露** | How agents load skills: name + description at startup → full SKILL.md on activation → bundled files on demand. / agent 加载 skill 的方式：启动读名称+描述 → 触发读完整 SKILL.md → 按需读打包文件。 |
| **skills CLI** | The npm CLI (`npx skills`) for installing and managing agent skills from GitHub repos. See https://skills.sh. / 从 GitHub 仓库安装管理 agent skill 的 npm CLI（`npx skills`）。见 https://skills.sh。 |
